# Linux Security Lab

This project documents the setup, assessment, hardening, and security testing of an Ubuntu Server virtual machine running in Oracle VirtualBox.

## Objectives

- Perform Linux system enumeration
- Identify security weaknesses and misconfigurations
- Apply security hardening measures
- Verify security improvements
- Document findings and remediation

## Environment

- Operating System: Ubuntu Server 26.04 LTS
- Virtualization: Oracle VirtualBox
- Network Mode: NAT
- Architecture: x86-64
