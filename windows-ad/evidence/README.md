# Evidence

This directory contains screenshots and supporting evidence from the Windows Active Directory home lab

## Evidence Categories

### 01 — Windows Server Configuration

Evidence of the Windows Server 2022 environment and DC01 server configuration

### 02 — Windows Server Installation

Evidence of the Windows Server 2022 installation used to build the Active Directory home lab

### 03 — Active Directory

Evidence of the `lab.local` domain, domain controller, and Organizational Units

### 04 — Users and Groups

Evidence of the Test User, Lab Admin account, and Active Directory security groups

### 05 — GPO Testing and Troubleshooting

Evidence of Group Policy testing using `gpupdate /force` and `gpresult /r`

The testing was used to verify Group Policy processing and investigate policy/application issues

An authentication issue was also encountered during testing where the Test User's password was rejected

The issue was investigated using Active Directory Users and Computers and Group Policy troubleshooting tools

This demonstrates a realistic troubleshooting scenario involving user authentication and Active Directory configuration

## Note

The evidence focuses on the key configuration, identity management, Group Policy, and troubleshooting stages of the lab.
