# Evidence

This directory contains screenshots and supporting evidence from the Windows Active Directory home lab.

## Evidence Categories

### 01 — Windows Server Configuration
Evidence of the Windows Server 2022 installation and DC01 configuration.

### 02 — Active Directory
Evidence of the `lab.local` domain, domain controller, and Organizational Units.

### 03 — Users and Groups
Evidence of Test User, Lab Admin, and Active Directory security groups.

### 04 — Group Policy
Evidence of `GPO-Lab-Users-Security` and its configuration.

### 05 — GPO Testing
Evidence of Group Policy testing using `gpupdate` and `gpresult`.
